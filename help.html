Ayuda

Aquí encontrarás información básica para utilizar Kn Foundation Account y solucionar problemas comunes.

No puedo iniciar sesión

Comprueba tu nombre de usuario Utiliza el nombre de usuario de tu cuenta de Kn Foundation. Ya no necesitas utilizar un correo electrónico para iniciar sesión.
Comprueba tu contraseña Asegúrate de escribir correctamente tu contraseña. Las mayúsculas y minúsculas pueden ser importantes.

No puedo crear una cuenta

Nombre de usuario El nombre de usuario debe tener al menos 3 caracteres y utilizar únicamente caracteres permitidos por Kn Foundation.
Nombre de usuario ocupado Si el nombre de usuario ya está siendo utilizado, tendrás que elegir uno diferente.

Problemas con la foto de perfil

Formatos compatibles Kn Foundation Account admite imágenes JPG, PNG, WEBP y GIF desde la interfaz de la cuenta.
Tamaño de la imagen Las imágenes demasiado grandes pueden ser rechazadas por el servidor.

La foto de perfil se almacena de forma centralizada y puede utilizarse en las aplicaciones compatibles con Kn Foundation Account.

Mi sesión se cerró

Las sesiones de Kn Foundation utilizan tokens de autenticación. Una sesión puede dejar de ser válida cuando el token caduca o cuando se cierra la sesión.

Inicia sesión nuevamente para obtener una nueva sesión.

Una aplicación no reconoce mi cuenta

Comprueba tu sesión Asegúrate de haber iniciado sesión en Kn Foundation Account antes de abrir la aplicación.
Aplicaciones compatibles Solo las aplicaciones configuradas para utilizar Kn Foundation API podrán utilizar tu cuenta.

Errores de conexión

Si aparece un mensaje indicando que no se puede conectar con Kn Foundation API, comprueba que el servidor esté funcionando y que la aplicación pueda acceder a él.

Seguridad

Nunca compartas tu contraseña ni tu token de sesión. Tampoco introduzcas tus credenciales en páginas que no pertenezcan a Kn Foundation.

¿Necesitas más ayuda?

Para problemas que no estén cubiertos aquí, utiliza los canales oficiales de soporte de Kn Foundation.
